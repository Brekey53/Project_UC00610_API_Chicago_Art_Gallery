# Galeria de Arte de Chicago - Explorador 3D

Este projeto é uma aplicação web interativa que permite aos usuários explorar a vasta coleção de arte do Art Institute of Chicago. Além de uma galeria de arte tradicional com pesquisa e paginação, o projeto apresenta um portfólio 3D imersivo e um jogo de tiro em primeira pessoa oculto. (Parte 3D formada por IA)

## ✨ Principais Funcionalidades

- **🖼️ Galeria de Arte:** Navegue e pesquise por milhares de obras de arte da coleção do Art Institute of Chicago.
- **🔍 Pesquisa com Debounce:** Uma função de pesquisa otimizada para encontrar obras de arte rapidamente.
- **📄 Paginação:** Navegue facilmente por várias páginas de resultados de obras de arte.
- **🎨 Detalhes da Obra de Arte:** Clique em uma obra de arte para ver informações detalhadas sobre ela.
- **🕹️ Portfólio 3D e Jogo Oculto:** Explore uma galeria 3D virtual construída com Three.js e React Three Fiber. Descubra o "Easter Egg" para jogar um mini-jogo de tiro em primeira pessoa!
- **👨‍💻 Sobre:** Uma página dedicada a falar um pouco sobre o desenvolvedor do projeto.

## 🚀 Tecnologias Utilizadas

- **[React](https://react.dev/)**: Uma biblioteca JavaScript para construir interfaces de usuário.
- **[Vite](https://vitejs.dev/)**: Uma ferramenta de construção que visa fornecer uma experiência de desenvolvimento mais rápida e enxuta para projetos web modernos.
- **[React Router](https://reactrouter.com/)**: Para roteamento e navegação na aplicação.
- **[Three.js](https://threejs.org/)** e **[React Three Fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction)**: Para a criação da galeria 3D e do jogo.
- **[Axios](https://axios-http.com/ptbr/docs/intro)**: Para realizar requisições HTTP à API do Art Institute of Chicago.

## 🏁 Começando

Para executar este projeto localmente, siga os passos abaixo.

### Pré-requisitos

- [Node.js](https://nodejs.org/) (versão 16 ou superior)
- [npm](https://www.npmjs.com/) (geralmente vem com o Node.js)

### Instalação

1.  **Clone o repositório:**
    ```sh
    git clone https://github.com/Brekey53/Project_UC00610_API_Chicago_Art_Gallery.git
    ```
2.  **Navegue até o diretório do frontend:**
    ```sh
    cd Project_UC00610_API_Chicago_Art_Gallery/chicago-gallery
    ```
3.  **Instale as dependências:**
    ```sh
    npm install
    ```

### Executando a Aplicação

Depois de instalar as dependências, você pode iniciar o servidor de desenvolvimento:

```sh
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) (ou o endereço que aparecer no seu terminal) no seu navegador para ver a aplicação.

## 📜 Scripts Disponíveis

No diretório `chicago-gallery`, você pode executar:

- `npm run dev`: Inicia o servidor de desenvolvimento.
- `npm run build`: Compila a aplicação para produção.
- `npm run lint`: Executa o linter para verificar a qualidade do código.
- `npm run preview`: Inicia um servidor local para visualizar a versão de produção.
